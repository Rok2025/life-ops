# 财务页改为支出记账

日期：2026-09-07。状态：代码完成并通过测试、构建。版本发布以本文件所属提交及远程分支为准；本文不代表生产部署已完成。

## 页面行为

- 财务访问验证继续保留，通过验证后直接显示月度支出账本，默认本月。
- 可选择历史月份、回到本月，查看笔数、金额合计及按日分组的记录。
- 保留新增支出、详情、修改、删除确认和当前月份 Excel 导出。
- 新增固定为支出，移除收入、还款、转账类型选择；编辑兼容已有支出的历史分类。
- 移除信用卡、还款安排、资产、负债、预算、基础信息和月度快照面板。
- 删除旧综合仪表盘组件，拆分为页面、账本、记录行和录入表单。

## 数据边界

仅调整网页展示和查询。财务表、既有记录、支付账户及 CLI 写入协议均保留，未执行数据库迁移或线上数据写入。

网页查询交易账户时只读取 id、名称、启用状态，不读取余额、额度、账单日等信息；查看财务页不再自动初始化财务数据。月度查询固定按当前用户及 expense 类型过滤，分批读取完整月份，避免记录被单次返回上限截断。查询失败提供重试，不显示为正常空账本。
