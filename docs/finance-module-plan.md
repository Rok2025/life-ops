# 财务模块实施方案

## 目标

财务模块第一阶段不是做复杂复式记账，而是建立一个能监督还债、提醒还款、记录支出、支持月度复盘的个人财务闭环。

核心目标：

- 清楚看到当前总负债、信用卡应还、固定月供和可用于还款的现金流。
- 每个还款日前有状态跟进，避免漏还、逾期和失去信用卡免息期。
- 每月按账单日更新信用卡已出账与未出账金额。
- 用轻量支出记录追踪钱花在哪里。
- 每月底生成月度快照，观察负债是否下降。

## 实施阶段

### 第 1 阶段：基础账本

建立以下数据表：

- `finance_profiles`：月收入、日常预算、目标可还款金额等个人配置。
- `finance_accounts`：信用卡、贷款、投资、现金等账户。
- `finance_liabilities`：房贷、闪电贷、家庭欠款等长期债务。
- `finance_credit_card_bills`：每月信用卡账单。
- `finance_payment_schedules`：还款跟进计划。
- `finance_transactions`：轻量收支记录。
- `finance_budgets`：月度预算。
- `finance_monthly_snapshots`：月度财务快照。

安全要求：

- 财务数据必须按 `user_id` 隔离。
- 开启 RLS。
- 查询、插入、更新、删除都限制为 `user_id = auth.uid()`。

### 第 2 阶段：还款监督

财务页需要展示：

- 顶部总览：总负债、信用卡应还、固定月供、预计可还款。
- 未来 30 天还款提醒。
- 信用卡账单卡片。
- 债务进度列表。
- 还款状态：`待确认`、`待还款`、`已安排`、`已还清`、`有风险`。

监督规则：

- 到期日前 7 天进入跟进视野。
- 到期日前 3 天仍未标记已安排，显示警示。
- 到期日前 1 天仍未还清，显示高风险。
- 已逾期且未还清，显示逾期风险。
- 信用卡应还超过预计可还款额时提示现金缺口。

### 第 3 阶段：支出记录

记录字段：

- 日期
- 金额
- 类型：支出、收入、还款
- 分类：餐饮、交通、家庭、育儿、住房、医疗、购物、人情、订阅、债务还款、其他
- 账户
- 备注

月度汇总：

- 本月支出合计。
- 本月还款合计。
- 日常消费预算使用率。
- 最大支出分类。

### 第 4 阶段：月度复盘

每月固定动作：

1. 工资到账后确认本月收入。
2. 信用卡账单日后更新已出账应还和未出账消费。
3. 还款日前标记还款状态。
4. 月底生成财务快照。
5. 对比上月总负债变化。

月度快照完善分三档落地：

1. 快照详情：点击快照卡片查看完整字段，包括总资产、总负债、信用卡债务、净值、月收入、月支出、月还款、备注和生成日期。
2. 月度复盘：在详情中展示与上月相比的总负债、净值、支出、还款变化，并结合当前预算和目标还款额提示预算使用、还款达标情况。当前月快照额外展示本月最大支出分类。
3. 趋势视图：在快照区展示最近快照的总负债、净值、月支出和月还款趋势，用于积累 3-6 个月后观察长期变化。

## 手动维护节奏

| 数据 | 更新频率 |
|---|---|
| 信用卡额度 | 有变化才更新 |
| 账单日、还款日 | 有变化才更新 |
| 信用卡已出账应还 | 每个账单日后更新 |
| 信用卡未出账消费 | 每周或账单日前更新 |
| 贷款剩余本金 | 每月更新 |
| 股票账户金额 | 每月更新 |
| 日常支出 | 每周至少更新一次 |
| 月度快照 | 每月底更新 |

## 第一版不做的事

- 不接入银行自动同步。
- 不做复杂复式记账。
- 不做投资收益分析。
- 不自动推断信用卡利息和分期成本。

这些能力等基础数据稳定后再扩展。
